# Модифицированные биосы для maxsun LGA1700

![Screenshot](screenshot.png)

Есть 3 биоса: `*_1`, `*_2`, `*_3`

`*_1` это биос с анлокнутым разделом overclocking performance menu и выключенным undervolt protection

`*_2` это биос с разблокированным меню и полностью сняты ограничения с настройки напряжений

`*_3` это биос со всеми разблокированными функциями в разделе, а так же разблокированны функции в меню turbo

## ⚠️ ВСЁ ДЕЛАЕТСЯ НА ВАШ СТРАХ И РИСК

Биосы проверены только с эмуляцией запуска с самописной программе, на ряльных платах не проверял

Сначала рекомендую прошить `*_1`, если регулировка напряжения все равно не доступна то `*_2`, если вам нужна настройка частот для мутантов то `*_3`

Если вы прошили биосы то рекомендую написать мне в тг о том что работает/не работает: **@rx580_2048**
